# Kristian Ray Parial — Portfolio

Personal portfolio website for **Kristian Ray Parial**, an IT graduate and full-stack web developer with experience in frontend development, backend integration, UI/UX design, and digital content management.

🔗 **Live Demo:** [kristianrayportfolio.vercel.app](https://kristianrayportfolio.vercel.app)

---

## Sections

| Section | Description |
|---------|-------------|
| About | Introduction, background, and profile photo |
| Skills | Frontend, Backend, and Languages skill sets |
| Experience | Roles and responsibilities at Filipino Web3 |
| Projects | Showcase of personal and production projects |
| Contact | Email button and Calendly scheduling link |

---

## Features

- Animated entrance and scroll animations via GSAP + ScrollTrigger
- Calendly popup widget for scheduling calls
- Responsive design — desktop, tablet, and mobile
- SEO optimized — meta description, keywords, canonical, Open Graph, Twitter Card, JSON-LD structured data
- Security best practices — `rel="noopener noreferrer"` on all external links

---

## Tech Stack

- HTML, CSS, JavaScript
- [GSAP](https://gsap.com/) + ScrollTrigger for animations
- [Calendly Widget](https://calendly.com/) for scheduling
- Deployed on [Vercel](https://vercel.com/)
